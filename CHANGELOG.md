# Changelog

## 0.1.0

### Signing, configuration, and service deployment

- Optional Ed25519 publication signatures and local trust policy.
- TOML node configuration with runtime RF application and readback.
- Library and inspection commands.
- Hardened systemd installation with bounded volatile logging.

### Documentation and presentation

- Product documentation, RF primer, deployment guidance, and security model.
- Self-contained HTML/PDF presentation with physical demo recordings.

### Core replication

- Hardware-verified dumb-modem firmware and Go serial client.
- Reliable multi-packet transfer with SHA-256 verification and durable partial state.
- Unified peer nodes with relay, resume, source switching, and receiver-driven acquisition.
- Radix reconciliation, local signing/trust policy, and runtime RF configuration.
